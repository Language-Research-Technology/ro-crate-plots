# Visualisation tools for RO-Crates

**This code is in active development**

This repository provides functions for visualising RO-Crates using 
[Vega](https://vega.github.io/vega/) plotting framework.

The overall workflow at this stage:

+ Process RO-Crate metadata into tabular datasets as CSV (e.g., using 
    [roctable](https://github.com/ptsefton/roctable)) or JSON; you can also use 
    any other tabular datasets
+ Write a config specifying which data to use and which plots to make
+ Call the `renderTemplate` function from `lib/render.js` to render Nunjucks
    HTML template (`template.html`) into a self-contained HTML with plots

## Config file structure

```
{
  "plots": {
    "globalConfig": {
      "actions": false
    },
    "datasets": {
      "dataset1": "./dataset1.csv",
    },
    "plotList": [
      {
        "dataset": {
          "name": "dataset1",
          "embed": false
        },
        "makeSpec": {
          "plotFunction": "barPlotCount",
          "args": {}
        },
        "generatedSpec": {},
        "customSpec": {},
        "config": {},
        "plotCardSpan": 1
      }
    ]
    }
}
```
+ `globalConfig` -- Vega embedding options, applied to all plots (see:
    https://vega.github.io/vega-embed/#options)
+ `datasets` -- each dataset is a path to CSV or JSON file (paths are relative
    to the config file location)
+ `plotList` -- an Array where each element corresponds to a plot:
    + `dataset` -- dataset to be used with this plot.
        + `name` -- one of the entires from `datasets`
        + `embed` -- if true, the data will be embedded directly into the plot
            spec; if false, it will be embedded into the HTML and can be shared
            between several plots. Map plots will force this to be true.
    + `makeSpec` -- config for one of the wrapper functions for generating
        basic Vega and Vega-lite specs. 
        + `plotFunction` -- function name (see `lib/plots.js` and `lib/mapplots.js`)
        + `args` -- function arguments
    + `generatedSpec` -- when the rendering function is run once, this section
        will be populated with the spec generated by the function listed in 
        `makeSpec`. Useful for debugging or custom tweaking.
    + `customSpec` -- any valid Vega or Vega-lite spec. If this is present, it
        will be used, and `makeSpec` and `generatedSpec` will be ignored. 
        Datasets can still be specified outside of the spec as described above.
    + `config` -- Vega embedding options for this specific plot, will take 
        priority over `globalConfig`
    + `cardsSpan` -- How many columns should the plot take in the rendered
        HTML; can be 1, 2 or 3.
